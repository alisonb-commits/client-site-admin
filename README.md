## Admin Dashboard (JWT Protected)

This project includes a secure admin dashboard that allows authenticated users to:
- log in using email/password
- receive a JWT token
- edit website content stored in PostgreSQL
- save changes via protected API routes

### Tech stack
- React (Vite)
- Node.js / Express
- PostgreSQL
- JWT authentication
